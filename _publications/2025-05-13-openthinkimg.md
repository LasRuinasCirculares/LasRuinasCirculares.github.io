## Abstract

OpenThinkIMG is an open-source framework for tool-augmented large
vision-language models. It provides standardized visual tool interfaces,
scalable trajectory generation, and V-ToolRL, a reinforcement learning method
that enables models to learn adaptive policies for invoking external visual
tools during reasoning.
